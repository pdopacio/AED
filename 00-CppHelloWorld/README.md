## Compilador

Se utilizó el compilador **G++ (GNU Compiler Collection)**.

- Versión del compilador: 15.2.0
- Estándar de C++ utilizado: C++20

La versión del compilador se obtuvo mediante el comando:

g++ --version

El compilador permite seleccionar la versión del lenguaje mediante la opción `-std`, en este caso se utilizó `-std=c++20`.
